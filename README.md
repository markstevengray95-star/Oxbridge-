# Oxbridge Interview Tutor

An interactive preparation app for students applying to Oxford or Cambridge.

## Included

- Guided, subject-specific interview practice across seven course families
- Adaptive tutor prompts and structured feedback on reasoning, subject use, flexibility and clarity
- Original TMUA, ESAT, TARA, LNAT and UCAT-style practice questions with explanations
- Oxford and Cambridge 2027-entry route guidance
- Interview-day checklist, personal-statement defence prompts and the C–T–T–R thinking method
- Automatic progress saving in the browser
- Responsive desktop and mobile interface

The app uses original practice material. Students should always confirm current requirements and use official test-provider materials for definitive specifications.

## Run locally

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```
